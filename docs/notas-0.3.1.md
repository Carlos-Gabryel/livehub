## Novidades

**Doações do LivePix** — as doações (Pix) agora aparecem no feed e disparam os alertas de doação (com TTS, se estiver ligado), como as do StreamElements.
- Configure em *LivePix* nas configurações: no painel do LivePix vá em Configurações → API → Nova Aplicação, com a permissão `messages:read`, e copie o Client ID e o Client Secret. O botão *Testar conexão* confere as credenciais sem gerar eventos.
- Doações antigas não geram alerta: ao conectar, o LiveHub só registra o que já existe e avisa a partir das próximas.
- **Desative o widget de alertas do próprio LivePix no OBS**, senão cada doação aparece duas vezes.

**Atualização** — esta é a primeira versão instalada pelo atualizador automático: ao abrir a 0.3.0, aceite a atualização (ou ela é instalada ao sair, conforme sua escolha em Avançado).
